# 脚本10学习笔记：固定姿态抓取流程 Demo

对应文件：[`scripts_archive/10_grasp_tube_demo.py`](../10_grasp_tube_demo.py)

## 1. 这个脚本解决什么问题

检测黄色试管中心，把像素转换为机械臂目标点，并按一组现场固定关节位执行第一版流程。

## 2. 输入、输出和副作用

- 输入：RealSense/模型，或 dry-run 的 `--pixel U V`；可选 CArm IP 和 `--execute`。
- 输出：默认打印动作计划；execute 模式会真实控制 CArm。
- 是否接触硬件：请结合下面的运行模式和注意事项判断；没有 `--execute` 不代表所有视觉脚本都不会打开相机。

## 3. 主流程

1. 检测并锁定黄色中心和可选图像角
2. 读取外部手眼矩阵并计算目标上方 TCP
3. 打印固定动作序列
4. 默认在预览模式结束
5. execute 时连接 CArm、检查零位并逐步运动
6. 松爪后返回零位并断开

## 4. 建议阅读顺序

- `find_yellow_geometry()`：管身中心和 B→C 图像角
- `pixel_to_arm_plane()`：像素射线到机械臂平面
- `move_to_fixed_target()`：固定关节运动和到位检查
- `execute_demo()`：按 1/11～11/11 执行动作

初学者建议先读文件末尾的 `main()`，看清调用顺序后再回头阅读上面的辅助函数。

## 5. 本脚本涉及的 Python 语法

- 常量集中保存现场确认姿态，运行变量与固定参数分开
- 闭包回调保存 SDK 异步错误
- `with`/`finally` 确保断开机械臂
- 确认文字把本次 x/y/z 写入字符串，减少误执行旧目标

## 6. 数学或领域知识

中心位置使用手眼矩阵和固定平面求交；脚本10只显示图像角，不把它用于动态 yaw。四元数顺序为 `[qx,qy,qz,qw]`，位置单位为米。

## 7. 常用命令

\`\`\`bash
python scripts_archive/10_grasp_tube_demo.py
\`\`\`

\`\`\`bash
python scripts_archive/10_grasp_tube_demo.py --pixel 690 134
\`\`\`

\`\`\`bash
python scripts_archive/10_grasp_tube_demo.py --ip 10.42.0.101 --execute
\`\`\`

脚本10固定使用 FP32 推理。

## 8. 容易混淆的地方

这是固定点位实验脚本，运行 execute 前必须从零位开始、清空扫掠区域并准备急停。不能把“SDK 接受命令”误认为路径无碰撞。

## 9. 学习检查题

- 这个脚本的输入数据来自哪里？
- 哪一个函数产生最终结果？
- 坐标、长度和角度分别使用什么单位？
- 发生异常时，文件、相机或机械臂连接在哪里释放？
- 哪些检查只能降低风险，不能证明真实路径绝对安全？
